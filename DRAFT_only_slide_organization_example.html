Slide C · one question: what is bootstrap here?

Inside each forest: bootstrap patients

Separate idea from GridSearch · happens for every tree, every fit

1. Development patients

455 labeled samples in the training fold / final fit.

→
2. Bootstrap bag

Each tree draws 455 rows with replacement. Some patients repeat; some are left out (OOB).

→
3. Grow + vote

Train that tree on its bag. Forest averages votes across trees (e.g. 300).

Bootstrap = rows

  • Resamples patients, not features
  • Default in sklearn: bootstrap=True
  • You did not hand-code the bags

Feature randomness = columns

  • Winner used max_features='sqrt'
  • ≈ √30 ≈ 5 features per split
  • Different from bootstrap
Say: CV chooses hyperparameters; bootstrap builds diversity inside the forest C / 3
