Breast Cancer Detection Using Random Forest

Final Project Presentation

Machine Learning
Wisconsin Diagnostic Breast Cancer (WDBC) Dataset
~12 minutes

1. Problem Statement & Motivation

  • Problem: Classify breast tumors as benign or malignant from digitized fine-needle aspirate features.
  • Why it matters: Early, accurate detection supports clinical decision-making and can reduce false reassurance or unnecessary procedures.
  • ML opportunity: Morphological features (radius, texture, area, concavity, etc.) are measurable and suitable for supervised learning.
  • Goal: Build a reliable, interpretable classifier with strong generalization on a locked holdout set.

2. Dataset Description

  • Source: Wisconsin Diagnostic Breast Cancer (WDBC)
  • Samples: 569 tumors · Features: 30 numeric (mean / SE / worst of 10 measurements)
  • Target: diagnosis → Benign (0) / Malignant (1)
  • Split: Development 455 (80%) · Final holdout 114 (20%), locked
  • Preprocessing: Cleaned IDs/labels; unscaled features (tree models do not require scaling)

Files: development_unscaled.csv · test_unscaled_FINAL_HOLDOUT.csv

3. Methods / Algorithms

  • Primary model: Random Forest Classifier (ensemble of decision trees)
  • Each tree trained on a bootstrap sample; random feature subset at each split
  • Final label by majority vote across trees
  • Class balancing: class_weight = balanced_subsample
  • Tuning: GridSearchCV + 5-fold stratified CV on development set (optimize accuracy)

Best model: 300 trees · max_features=sqrt · min_samples_split=5 · max_depth=None

4. Project Workflow

  1. Clean WDBC → 30 features + diagnosis
  2. 80/20 stratified split → development vs locked holdout
  3. GridSearchCV over forest hyperparameters (5-fold CV)
  4. Refit best model; report CV metrics
  5. Evaluate once on holdout (accuracy, F1, MCC, ROC-AUC, confusion matrix)
  6. Analyze feature importance for interpretability

7. Analysis & Baseline Comparison

  • Why Random Forest: Handles nonlinear interactions, robust to feature scale, provides feature importance.
  • Vs. a single decision tree: Forest reduces variance via bagging + feature randomness → more stable CV accuracy.
  • Vs. linear models: Tumor morphology often involves nonlinear boundaries; RF captures these without heavy feature engineering.
  • Error analysis: All errors were false negatives (3/42 malignant). Clinically important — prioritize recall in future tuning.
  • Top features: area_worst, perimeter_worst, concave_points_worst/mean, radius_worst (size + shape irregularity)

9. Future Directions

  • Optimize for recall / cost-sensitive learning to reduce false negatives further.
  • Compare stronger baselines: Logistic Regression, SVM, Gradient Boosting/XGBoost (same split).
  • Calibration of predicted probabilities for clinical risk communication.
  • Feature reduction / ablation using importance rankings.
  • External validation on additional cohorts beyond WDBC.
  • Explainability: SHAP values for case-level explanations.

10. Conclusion

  • Built a tuned Random Forest for breast cancer classification on WDBC.
  • 5-fold CV accuracy ≈ 96.5%; holdout accuracy ≈ 97.4%.
  • Excellent discrimination (ROC-AUC ≈ 0.996) with zero false positives on holdout.
  • Remaining gap: 3 missed malignant cases → future work targets recall.
  • Model is accurate, stable, and interpretable via feature importance.

Appendix — Anticipated Questions

  • Why unscaled features? Tree splits are scale-invariant; scaling unnecessary for RF.
  • Why not deep learning? Tabular, small-n dataset; RF is strong, interpretable, and less overfit-prone here.
  • Class imbalance? Used balanced_subsample; malignant recall still the main residual error.
  • Data leakage? Holdout locked; tuning only on development CV.
