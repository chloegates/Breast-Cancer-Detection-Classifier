Model workflow · starts at tuning

From GridSearch to interpretation

Development set first · holdout touched only once at the end

1

GridSearchCV over forest hyperparameters

Search the hyperparameter grid with 5-fold stratified CV on the development set (455 samples). Score each combo by mean fold accuracy.

Output Best settings among 96 combinations
2

Refit best model; report CV metrics

Retrain the winning forest on the full development set. Summarize CV mean ± std (accuracy, and supporting metrics).

Output Mean CV accuracy 0.9648 ± 0.0128
3

Evaluate once on holdout

Score the locked test set (114 samples) one time: accuracy, F1, MCC, ROC-AUC, and confusion matrix.

Output Holdout accuracy 0.9737 · no further tuning
4

Analyze feature importance

Rank features from the fitted forest for interpretability (e.g., area_worst, perimeter_worst, concave points).

Output Top drivers of malignant vs benign predictions
